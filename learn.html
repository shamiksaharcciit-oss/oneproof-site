Learn

Every level you pass leaves a record anyone can check.

Each level is a task with a definite output: a run folder, a comparison, or a refusal the verifier names. You pass when the verifier says so, on your own machine, with no account.

B

Build

Record a run, change one setting, sign it, timestamp it. The output is a run folder the verifier passes.

X

Break it

Make the verifier refuse in a named way, such as editing a receipt after the run. You learn what the record protects.

?

Detective

Two runs on the live demo and a changed answer. Which step changed first, and what setting changed there?
